3 · When it goes wrong: every failure says why and offers a way on

The one to plan for: the defence room is indoors, where the NEO-6M usually can't see enough satellites. So "online but no GPS" (d) is a normal state with a clear next step, and the recorded walk (f) keeps the map moving.

What this needs that doesn't exist yet

Pi check-in without a fixToday the Pi only sends when it has a position. It should also report "online, N satellites" each tick. Small change to the Pi code and to collar-ingest; drives 5, c and d.
Claim codesCollars get registered once, before anyone owns them, with a sticker code; pairing claims one. Replaces the .env copy-paste. One migration.
Recorded-walk replayRe-sends a walk the collar really recorded through collar-ingest, clearly marked as a recording. Needs a mechanism we pick in the approaches step.
Live pushThe page polls every 30 s today. Realtime makes each position appear in about a second, which the demo depends on.
Battery: left out on purposeThe Pi doesn't measure it yet (it sends nothing), so no battery is shown anywhere. The sidebar mockup's "82 %" goes.
